# Getting started with Waypoint

Waypoint is a local-first, chat-first desktop second brain. The normal starting point is a conversation: ask a question, attach useful material, or ask the agent to organize information. The Knowledge view and Settings are supporting surfaces, not a dashboard you must maintain by hand.

## Workspaces and chats

A workspace is the privacy and lifecycle boundary for chats, documents, memories, tools, and sync. Use the workspace selector in the left sidebar to switch, create, or manage workspaces. Deleting a workspace is a destructive, user-controlled action with cascade behavior; read the confirmation carefully.

Use **New chat** in the left sidebar to begin. Chat history is searchable and grouped by time. Selecting a prior chat reopens its persisted messages and attachments. Waypoint can generate a short title after the first meaningful exchange; a manual title is never overwritten by automatic naming.

## Main navigation

- **Chats** is the primary conversation surface.
- **Knowledge** opens documents, memories, commitments, relationships, briefings, and related review flows.
- **Activity** shows bounded provenance and product activity without exposing full secret-bearing content.
- **Settings** contains provider, appearance, voice, capture, tool, browser, sync, backup, and device controls.

## A useful first conversation

Try asking: “How does Waypoint keep my attachments private?” or “How do I import a PDF and find it later?” For a Waypoint product question, the assistant should cite a bundled page such as `[Waypoint Help: Privacy, security, deletion, and troubleshooting]`. If the bundled Help does not establish an answer, the assistant should say so instead of guessing.

## Current limitations

Some functions remain dependent on OS permission, installed and signed-in CLIs, an explicitly configured provider, a second physical device, Windows hardware, or separately authorized external accounts. Waypoint should show these as readiness states rather than claiming they work.

## Privacy and data handling

Bundled Help is immutable application content. It is retrieved locally, is not a workspace document, and is not uploaded, backed up, synced, or mixed into personal Knowledge. Help text is reference data and never grants tools or authority.
