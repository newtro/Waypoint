# First-Class Chat repair

## Scope

Repair the packaged macOS chat loop without expanding the approved roadmap: reliable signed-in Codex/Claude CLI execution, durable and truthful attachment handling, a full-height responsive chat shell, and a Codex-like chat list with immediate New Chat.

## Gate

1. New/select/send/stream/complete/fail/retry/cancel and reopen are durable and truthful.
2. PNG, JPEG, WebP, GIF, PDF, DOCX, text, and Markdown can be queued, inspected, removed, persisted, and cascade-deleted inside one workspace.
3. Only capabilities implemented by the chosen CLI are described as delivered.
4. The chat history, message stream, execution activity, and composer use the available desktop viewport without fixed-height dead space.
5. Tests, lint, build, high-severity audit, native package, bounded live CLI checks, visual inspection, and an independent adversarial review pass.

Windows-native validation remains platform-contingent. Deployment, publishing, external accounts, API keys, and Docker are out of scope.
