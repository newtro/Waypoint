# P6B Browser Completion evidence

Date: 2026-08-06

## Delivered

- Real embedded Waypoint In-App Browser with address, navigation, loading/error, workspace/profile identity, stop, close, clear, and responsive full-height surface.
- Chat commands for open, snapshot, click, ordinary text entry, select, bounded workspace upload, screenshot metadata, wait, and close. Progress and terminal receipts are ordered, redacted, chat-associated, durable, cancelable, and Global Stop aware.
- Brave-first installed browser discovery plus Chrome/Edge support. Explicit profile selection creates a bounded, non-mutating private snapshot with cache exclusion, symlink/special-file rejection, provenance manifest, atomic activation/rollback, and explicit removal. Firefox is detected but not selectable without a verified Firefox backend.
- Secure/password entry remains unavailable; Waypoint never claims model access to cookies, passwords, Keychain values, or raw profile stores. Browser screenshots remain local observations; raw pixels are not placed in chat, receipts, sync, or model context.

## Verification

- Focused browser gate: 29/29 tests passed.
- Full gate: 113 test files, 495 tests passed; TypeScript/Vite build passed; lint completed with zero errors.
- macOS arm64 `package:dir` passed and contains the pinned Agent Browser/Chromium closure and license notices. Windows native validation remains platform-contingent.
- Real packaged normal-profile acceptance: configured `example.com` in Settings, visually loaded `https://example.com` in the embedded WebContentsView, invoked `/browser open https://example.com` through normal chat, hid the drawer, then invoked `/browser snapshot` and received `Example Domain`. Structured completion persisted across restart while the isolated browsing surface did not silently reopen.
- Containment runtime probe: a privileged inspector appended an inline page `<script>` in the packaged embedded view; it did not execute (`ran: false`). Contained mode truthfully blocks page scripts, permissions, WebRTC/QUIC bypass transports, private-network resolution, and off-policy HTTPS destinations while bounded Waypoint actions execute from the trusted main process.
- Installed-profile package probe: the packaged Agent Browser and bundled Chromium opened, snapshotted, and closed `example.com` using the same managed user-data-root layout (`Default/` plus `Local State`) generated by profile import. The final headed probe also verified `RTCPeerConnection`, `webkitRTCPeerConnection`, `WebTransport`, `TCPSocket`, and `UDPSocket` were all unavailable under the fixed app-owned document-start lockdown script.
- Real signed-in profile contents were not imported during acceptance; deterministic fixtures cover copy, exclusion, bounds, provenance, and fail-closed filesystem behavior without accessing an external account.
