# R0 — authority, trust, and protocol freeze

## Local scope

Freeze conservative local defaults and executable contracts without provisioning infrastructure, using credentials, or claiming hosted transport evidence.

## Acceptance gate

1. One canonical contract fixes protocol/schema support, node-visible metadata, envelope and backup retention, tombstone/peer policy, limits, recovery posture, supported native targets, and development release identity.
2. Executable fixtures cover version negotiation, key epochs, replay, revocation, maximum lifetime, recovery-manifest validation, and deletion dominance.
3. Architecture records map secrets and representative fields to storage visibility, retention owner, deletion, and recovery behavior.
4. Threat coverage includes connectors, audio, notifications, mobile loss, model fallback, and unattended execution.
5. Focused and full tests, lint, build, audit, package closure, and independent privacy/security review pass without blocker/high findings.

## External exclusions

No AWS/Ubuntu host, DNS, TLS, firewall, backup destination, external account, production credential, Windows machine, signing identity, publication, or real third-party data is used. Those remain R1/R2 gates.
